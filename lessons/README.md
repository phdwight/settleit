# Lessons

One-file-per-lesson store of durable corrections and confirmed approaches
for agents working in this repo. It sits beside the other agent docs
([../AGENTS.md](../AGENTS.md), [../handoff.md](../handoff.md)) and is
linked from the "Start here" list in [../AGENTS.md](../AGENTS.md). Read it
at the start of every session.

## Contract

- **One lesson per file.** Name files by topic, e.g.
  `sw-cache-versioning.md`.
- **One-line summary at the top** of each file, then the detail.
- **Record corrections and confirmed approaches alike**, and always the
  *why* — the reason a correction mattered is the reusable part.
- **Don't duplicate what's already recorded.** If
  [../handoff.md](../handoff.md), [../README.md](../README.md), or chat
  history already covers it, link there instead of re-recording.
- **Update, don't append.** Edit an existing note rather than adding a
  near-duplicate. Delete notes that turn out to be wrong — this store is
  edit-in-place, not append-only.
- **Live harness rules are not lessons.** The behavior rules in
  [../handoff.md §5](../handoff.md#5-agent-behavior-rules) belong there,
  not here.
